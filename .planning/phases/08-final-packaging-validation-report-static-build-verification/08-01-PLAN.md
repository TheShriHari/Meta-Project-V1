# Plan 08-01: Final Packaging, Validation Report, Presets CLI, Documentation & Static Smoke Tests

## Objective
Complete Phase 8 packaging (`TASK-801`–`TASK-805`) by implementing the deterministic preset CLI runner (`scripts/run_presets.py`), the automated validation report generator (`scripts/generate_validation_report.py` -> `docs/validation_report.md`), scientific limitations (`docs/limitations.md`), user/developer guide (`docs/user_guide.md`), and static bundle smoke tests (`web/tests/static_smoke.test.mjs`).

## Tasks
1. **Task 1 (Canonical Presets CLI):** Create `scripts/run_presets.py` executing the 5 canonical presets (`al_hansen_calibration`, `cu_hansen_ralph`, `fe_if_takeda`, `steel_c60_takeda`, `boundary_lrb_misorientation_sweep`) via `hpsim.core` with formatted console tables and optional `--json` export.
2. **Task 2 (Validation Report Generator & `docs/validation_report.md`):** Create and run `scripts/generate_validation_report.py` to evaluate `V-01` through `V-17` against exact tolerances and generate `docs/validation_report.md` including the full Phase 6 calibration/held-out table and physical analysis of BCC carbon segregation and FCC commercial-purity $\sigma_0$ offsets.
3. **Task 3 (Scientific Limitations & User Guide):** Write `docs/limitations.md` (covering 1D pile-up idealization, isotropic elasticity vs Zener anisotropy, nanocrystalline breakdown, solute boundary segregation, 2D optical stereology & random $\mathrm{SO}(3)$ orientations, and `RECONSTRUCTED_FROM_FIT`/`M3`/`D6` provenance guardrails) and `docs/user_guide.md` (covering CLI quickstart, all 5 interactive UI panels, and custom JSON/CSV chord dataset schemas).
4. **Task 4 (Static Build & Licensing Smoke Test):** Create `web/tests/static_smoke.test.mjs` verifying `web/public/data/materials.json`, checking that zero raw DoITPoMS `.jpg` files exist inside `web/public/` (`D6`), and checking `web/dist/index.html` asset path portability.
